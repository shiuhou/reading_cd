# 搜尋已有論文筆記

先確定使用者的筆記位置：明確路徑優先，其次 `OBSIDIAN_VAULT_PATH` 或已選研究設定中的 `vault_path`。預設論文子目錄是 `20_Research/Papers`，有 `papers_dir` 設定時沿用。位置未知時詢問，不把當前目錄當作 Vault。

用當前環境的檔案搜尋工具（例如 `rg -n -i -F --glob '*.md' -- '查詢詞' '論文目錄'`）定位候選，再按需讀取上下文。依问题擴充同義詞、縮寫或相近研究方向，區分精確命中與語義相關。按實際相關性整理，不必套用固定加分公式。

回覆論文標題、匹配理由、相關段落及可開啟的筆記路徑；作者與日期只在筆記有資料時提供。未找到結果時說明查過的範圍。單純搜尋不改寫筆記，也不自動轉成網路下載任務。

## 使用者另外要求搜尋並收藏網路論文時

`scripts/paper_hunter.py` 是會下載 PDF 和新增筆記的獨立工具，不是本地搜尋器。腳本路徑相對於本檔的實際目錄；先解析符號連結。可用 `--config`、`--vault`、`--papers-dir` 指定配置及目的地，用 `--source arxiv|pubmed|all` 和 `--max_results` 控制搜尋。設定路徑也可由 `RESEARCH_CONFIG_PATH` 指定；Vault 環境變數為 `OBSIDIAN_VAULT_PATH`。

此工具只用設定中的前五個關鍵字建立查詢，且只做淺層重複檢查。若任務需要完整覆蓋或 Vault 有分層目錄，先評估這些限制，必要時直接搜尋來源並按 ID／DOI 跨目錄查重。它產生的是摘要筆記，不是精讀報告。
